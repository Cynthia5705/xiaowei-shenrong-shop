# 🌿 小魏参茸土特产

一个用 **Flask + SQLite** 搭建的完整电商演示项目 —— 适合用来学习网上商店背后的
运作原理。支付全部为模拟操作，随便点、随便买，不花一分钱。

## 功能

- 📦 **商品列表**：分类筛选、关键词搜索、分页
- 🛒 **购物车**：加入 / 修改数量 / 移除 / 清空（登录后依然保留）
- 👤 **会员系统**：注册、登录、退出、我的订单
- 💳 **模拟结算**：校验收货信息、模拟扣款、自动扣减库存
- 🛠️ **管理后台**：销售数据概览、商品增删改查、订单状态管理

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

打开 **http://127.0.0.1:5000** —— 首次运行会自动创建 `shop.db`
并写入 17 件参茸土特产商品。

| 身份 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | `admin` | `admin123` |

结算时的银行卡号随便填 **16 位数字**即可通过（演示环境）。

```
├── checkout.py      # 模拟支付与订单确认     /checkout/*
├── admin.py         # 管理后台               /admin/*
├── templates/       # Jinja2 模板
├── static/css/      # 样式表
├── smoke_test.py    # 全流程自动化测试（需先启动服务器）

```

## 涉及的知识点

- **蓝图（Blueprint）**：把 Flask 应用拆分成清晰的模块
- **应用上下文与 `g`**：每个请求复用同一个数据库连接
- **Session**：登录状态和购物车都保存在签名 Cookie 中
- **密码哈希**：使用 `werkzeug.security`，绝不保存明文密码
- **装饰器权限控制**：`@login_required`、`@admin_required`
- **金额用「分」存整数**：避免浮点数精度问题
- **订单快照**：`order_items` 保存下单时的名称与价格，之后改价不影响历史订单
- **库存管理**：结算时二次校验，下单成功后自动扣减
- **运费规则**：满 ¥199 免运费，否则收 ¥10（见 `helpers.shipping_fee`）

## 重置数据库

停止服务器 → 删除 `shop.db` → 重新启动，即可自动重建并写入演示数据。
